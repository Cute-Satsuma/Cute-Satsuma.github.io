1. 简介

代理（“我们”、“我们的”或“本应用”）致力于保护您的隐私。本隐私政策说明了我们如何收集、使用和保护您的信息。

2. 我们收集的信息

代理 是一款 macOS 代理客户端。我们不运营代理服务器，也不要求注册账号。我们承诺：

  • 不收集个人信息：我们不会收集、存储或传输任何个人身份信息（如姓名、电子邮件地址、电话号码等）。
  • 配置留在本机：订阅地址、节点选择、设置和本地日志默认保存在您的 Mac 上，不会上传到我们的服务器。
  • 无数据收集：本应用不包含任何分析工具、广告网络或第三方数据收集服务。

3. 权限与系统能力

本应用可能使用以下能力：

  • 网络：用于拉取您添加的订阅、连接您配置的节点，以及查询当前公网 IP（便于确认出口）。
  • 系统代理 / VPN 相关设置：仅在您连接时修改本机网络设置；断开时按快照还原。本应用不会把流量发到由我们运营的服务器。

4. 数据使用

联网能力的用途是：

  • 从您填写的订阅 URL 下载配置（该订阅服务提供方可看到您的 IP 与请求）
  • 按您选择的节点转发本机流量；节点运营方可能看到途经该节点的流量
  • 向第三方 IP 查询接口请求当前公网地址，以便在界面显示（例如 ipify、ipw.cn、ipinfo、ip.sb 等）

我们不会查看、存储或出售您的上网内容。流量走向取决于您自己添加的订阅与节点，而不是 Caju 的服务器。

5. 数据存储

配置文件、订阅地址、已选节点、设置和内核日志保存在本机应用支持目录中。您可以在应用内删除配置，或删除应用数据目录以清除本地数据。

6. 数据共享

我们不会与任何第三方共享、出售或传输您的个人数据，因为我们不收集此类数据。您主动使用的订阅源、代理节点和 IP 查询接口会收到相应网络请求，并按其自身政策处理。

7. 第三方服务

本应用内核不含广告或统计 SDK。您添加的订阅服务、代理节点以及用于显示公网 IP 的第三方接口不受我们控制。请同时查阅这些服务的条款与隐私政策。

8. 儿童隐私

本应用不面向13岁以下的儿童。我们不会故意收集13岁以下儿童的个人信息。如果您是家长或监护人，并发现您的孩子向我们提供了个人信息，请联系我们，我们将立即删除此类信息。

9. 您的权利

由于我们不在服务器上收集个人数据，您无需申请服务端删除。您可随时删除本机配置、断开连接，或卸载本应用。

10. 隐私政策的变更

我们可能会不时更新本隐私政策。任何更改都会在此页面上发布，并更新“最后更新日期”。我们建议您定期查看本隐私政策以了解任何更改。

11. 联系我们

如果您对本隐私政策有任何疑问或疑虑，请通过 Caju 门户或 GitHub 组织 Cute-Satsuma 联系我们。

我们致力于保护您的隐私，并确保您在使用本应用时感到安全。
